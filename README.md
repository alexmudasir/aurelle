# AURELLE — Premium Fashion Store Design Demo

A premium fashion and apparel store design demo.

## What it does

- Editorial hero, Women / Men / Accessories collections
- 12 products with prices, ratings and sale badges
- Filters, sorting, live search and quick view with size and quantity
- Wishlist and slide-in cart drawer with free-shipping progress (free over $150)
- Light and dark mode toggle

## Live demo

https://astonishing-cuchufli-cd97d0.netlify.app/

## Notes

- This is a design demo. The checkout is a demo only and no real orders are placed.
